## 团队后端兼容

- 主群聚合接口返回 404 时，通过当前用户可访问的项目读取各项目群列表。团队版 `defaultGroup` 在 API 层映射为前端群类型。
- 团队后端缺少消息上下文接口时，旧通知仍可定位到目标消息。页面提示历史上下文不可用，完整的上下文加载取决于服务端提供对应接口。
- 团队 `main` 已有的 `QUOTE` 消息类型和显式触发任务接口差异继续保留。真实后端的引用与任务流程需要单独联调。
- 已读继续使用整群标记接口。基于实际阅读序号的已读规则属于 CHAT-009B。
